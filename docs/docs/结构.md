# Nexus Agent 项目结构说明

> 项目：**Nexus Agent（superagent-understanding）** —— 企业级多编排 AI 智能体平台
> 技术栈：Java 17 / Spring Boot 3.5 / Spring AI 1.1 / Spring AI Alibaba / MyBatis-Plus / MySQL / PostgreSQL(PGVector) / Elasticsearch / Neo4j / Redis / Redisson / Kafka / MinIO / Vue 3
> 说明：下文采用 Unicode 方框字符树形目录（Directory Tree）+ `#` 注释的形式，逐层说明各模块、包、类的作用。

---

## 二、业务主模块 nexus-agent-business

> 平台核心：唯一的业务子模块 `nexus-agent-business-chat` 是可运行的 Spring Boot 应用，
> 包含管理端认证、对话智能体（三层执行器 + RAG 编排 + ReAct Agent）、文档知识库治理、Prompt 模板管理四大块。

      └─► nexus-agent-redisson-framework（分布式锁、防重、租约、延迟队列）

        Neo4j（文档结构图谱）、Redis/Redisson（缓存与分布式协同）、Kafka（文档异步处理）、MinIO（原始文件）、Tika（解析）
