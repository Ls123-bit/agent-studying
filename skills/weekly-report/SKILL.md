# 周报撰写技能

当用户需要写周报、周总结、工作汇报时，按以下流程执行：

1. **收集素材**：从对话中提取用户提到的工作内容。如果用户没有给出具体内容，先追问本周做了哪些事，不要凭空编造。
2. **按模板组织**，输出以下四个固定板块：
   - **本周完成**：按"事情 + 结果/数据"的格式逐条列出，能量化尽量量化。
   - **下周计划**：3-5 条，按优先级排序。
   - **风险与问题**：当前阻塞项、依赖未就绪的事项，说明影响和需要的支持。
   - **需要的协助**：明确需要谁、做什么，方便主管直接行动。
3. **语言要求**：简洁、结论先行、动词开头；不写空话套话；单条不超过一行。
4. **输出格式**：使用 Markdown 小标题分块，方便直接粘贴到邮件或群聊。

参考 `template.md` 可以看到一份可直接套用的周报模板。
